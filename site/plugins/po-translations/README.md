# Kirby PO Translations

Version: `0.1b`
License: `GPL-3.0-or-later`

Reusable lightweight PO translation bridge for bilingual Kirby sites.

## Provides

- Loads `site/translations/tr.po`
- Loads `site/translations/en.po`
- `fa_t($key, $fallback, $locale)`
- `fa_field($model, $base, $locale)`
- `fa_language_url($locale)`
- Panel override support through `site_i18n_overrides`

## Kirby plugin id

`fatihalper/po-translations`
