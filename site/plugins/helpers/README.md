# Kirby Archive Helpers

Version: `0.1b`

Reusable project helper module for archive-style Kirby sites.

## Provides

- Content type registry
- Frontend metadata helpers
- Tag index helpers
- Dashboard stats and health summaries
- Cache clearing hook used by the Panel operations screen

## Public helpers

- `contentTypeRegistry()`
- `contentTypeLabel()`
- `contentPrimaryImage()`
- `contentCardMetadata()`
- `contentTagIndex()`
- `dashboardArchiveReports()`

## Kirby plugin id

`fatihalper/archive-helpers`
